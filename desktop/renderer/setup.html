Install local models

Local only mode needs no API key. After the models below are installed, recording, transcription, translation, and summaries run without a network connection.

  • Models come from third-party registries and carry their own licenses.
  • Downloads can be several gigabytes. Each model shows its size and source before you start.
  • Processing speed depends on this Mac. Long meetings can take a while to summarize.
